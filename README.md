# ReferralRail

ReferralRail v2 is a backend-free GenLayer referral campaign protocol.

Employer creates and fully funds a multi-position campaign. Referrers attribute candidates through client-side links. Candidates join, accept, submit evidence, and receive a reward when OutcomeJudgeV2 verifies completion. Referrers receive the attribution reward. Failed positions reopen capacity. Unused backing is refunded.

Evidence modes are GITHUB_PR and PUBLIC_WEB. GITHUB_PR is structured repository evidence. PUBLIC_WEB is any bounded publicly fetchable HTTPS page. X, Medium, DEV and other sites are frontend presets that map to PUBLIC_WEB.

V2 is isolated on chain 61997 and remains on branch referralrail-v2. V1 and main are unchanged.
